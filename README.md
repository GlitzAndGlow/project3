# Sales Dashboard (Power BI)

## Overview
This repository contains a Power BI report (`Project 3.pbix`) that presents an interactive **Sales Dashboard** for monitoring business performance through key sales metrics, trends, and category-level analysis.

## Dashboard Features
The report includes:

- KPI cards for high-level sales performance indicators.
- Interactive slicers for filtering report data.
- Column charts for comparative analysis.
- Area charts for trend analysis over time.
- Bar charts for ranking and performance comparisons.
- Treemap visualizations for contribution analysis.
- Donut charts for proportional distribution analysis.
- Images and branding elements for dashboard presentation.

## Report Structure
- **Page 1:** Sales Dashboard

## Key Visual Types Used
| Visual Type | Purpose |
|------------|---------|
| KPI Cards | Display key performance metrics |
| Slicers | Interactive filtering |
| Column Chart | Category comparison |
| Area Chart | Trend analysis |
| Bar Chart | Performance ranking |
| Treemap | Hierarchical contribution analysis |
| Donut Chart | Percentage distribution analysis |

## Requirements
To open and edit the report:

- Microsoft Power BI Desktop
- Access to the underlying dataset (if external refresh is required)

## How to Use
1. Open `Project 3.pbix` in Power BI Desktop.
2. Refresh the dataset if necessary.
3. Use the slicers to filter the dashboard.
4. Interact with visuals to explore detailed insights.
